# MAGNET — Store Copy (EN)

Short description:
Control a magnet with one finger and guide the core through physics puzzles.

Description:
MAGNET is a one-finger physics puzzle game built around magnetic movement, momentum, obstacles and short satisfying levels. Move the magnet, guide the core, reach the target and master each level with fewer moves.

Features:
- 100 levels
- 5 worlds
- 3-star progression
- Collectible skins
- Offline play
- Optional hint infrastructure
